# Sales Consultant Flow

The **Sales Consultant Agent** is a voice-native AI agent designed to interact with the customer over an audio stream. It uses Google's `LiveConnectConfig` to maintain an ultra-low latency, bidirectional WebSocket connection.

## Location
- `app/integrations/voice/provider.py` (WebSocket & Live API Handler)
- `app/agents/sales_consultant/agent.py` (Prompt & Tool definitions)

## Execution Flow

1. **Trigger**: The Orchestrator calls a local Node.js Electron bridge (`http://127.0.0.1:3456/simulate`) which visually initiates a phone call on the Electron App.
2. **WebSocket Connection**: The Electron App connects to `/api/v1/voice/ws`.
3. **Context Injection**: The backend pulls the `sales_consultant_context` generated by the Intent Agent from the database. It constructs a highly specific System Prompt ("You are a sales consultant calling {Name}...").
4. **Live API**: The backend initializes a `genai.Client().aio.live.connect` session using `models/gemini-2.5-flash-native-audio-preview-12-2025`.
5. **Streaming**: 
   - Audio chunks from the frontend are forwarded to Gemini.
   - Audio chunks from Gemini are forwarded back to the frontend.
6. **Function Calling (Tools)**:
   - When the user asks for recommendations, Gemini outputs a tool call: `request_product_recommendations`.
   - The provider intercepts this, calls the internal Orchestrator API (which runs the `ProductIntelligenceAgent`), and returns the exact recommendations back to Gemini.
   - When the user confirms a choice, Gemini outputs a tool call: `confirm_product_selection`.
   - The provider intercepts this, calls the Orchestrator, which triggers the `CommerceEngine` to add the item to the actual database cart.

## Error Handling

If a tool call fails (e.g., the `CommerceEngine` returns a `COMMERCE_DB_ERROR` because a product ID is invalid), the provider traps the error and returns a `system_directive` to Gemini. This directive forces Gemini to apologize to the customer and ask them to choose again, preventing a hard crash.
