# AI Agents Overview

The Agentic Commerce Copilot relies on three distinct AI Agents, each with a specialized role. They are never exposed to the user directly, except for the Sales Consultant.

## 1. Intent Agent
**Purpose:** Analyzes the raw behavioral events of a user session to deduce their actual intent.
**Trigger:** Automatically triggered by the Orchestrator when a session's deterministic intent score exceeds the `intent_threshold`.
**LLM Used:** High-intelligence model (e.g., Gemini 1.5 Pro or similar via `get_llm`).
**Inputs:** A structured JSON summary of the customer's behavioral events (e.g., product views, searches, time spent).
**Outputs:** `StructuredIntentOutput`, containing:
- `intent_category` (e.g., HIGH_PURCHASE_INTENT)
- `confidence`
- `buying_stage`
- `reasoning`
- `sales_consultant_context` (a summarized prompt for the next agent)
**Error Handling:** If it fails, it returns a fallback output of `LOW_INTENT` and `DO_NOTHING` so the system gracefully degrades.

## 2. Product Intelligence Agent
**Purpose:** Finds the absolute best products in the catalog based on the customer's requirements.
**Trigger:** Triggered by the Orchestrator when requested by the Sales Consultant.
**LLM Used:** High-speed model (e.g., Gemini 1.5 Flash).
**Inputs:** A structured "Mock Customer Requirement" generated from the conversation context.
**Tools Used:** `search_products`, `get_product_details` (though optimization pre-fetches catalog data to reduce LLM round trips).
**Outputs:** `ProductIntelligenceOutput` containing a list of `ProductRecommendation` (IDs, match scores, reasons).

## 3. Sales Consultant Agent
**Purpose:** A real-time conversational agent that talks to the customer to finalize the sale.
**Trigger:** Triggered via the Electron App (Phone UI) bridging WebSockets to the Gemini Live API.
**LLM Used:** `models/gemini-2.5-flash-native-audio-preview-12-2025` (Multimodal Realtime).
**Inputs:** The `sales_consultant_context` generated by the Intent Agent, plus real-time audio streams.
**Outputs:** Real-time audio streams, plus Tool Calls to the Orchestrator.
